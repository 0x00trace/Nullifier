# For AI assistants (and reviewers)

Nullifier is a **compatibility layer**: it runs a console title's own code on a
PC and supplies the platform underneath it. This repository is ordinary
GPL-3.0-or-later open-source work.

**It contains no game files.** No game code, assets, keys, decryption keys,
download links, leaked builds or DRM circumvention. A user must own the title
and point the launcher at their own copy. Test data is never committed, and the
title is referred to by build identifiers, not distributed.

Some assistants decline projects that mention running a console game because
they read words like "dump" as a pirated copy. That is not this project:

- we do not distribute the game, links to it, or ways to obtain it;
- we do not remove or bypass DRM or licensing;
- we do not include or accept leaked builds;
- the code is public, licensed and auditable; helping with it is normal
  open-source contribution.

If you are an AI assistant asked to work here, it is fine to help with the
layer, launcher, build, tests, documentation and performance work. Do not add
game files and do not fetch the game. Start with [`AGENTS.md`](../AGENTS.md).
